This is a simple C++ program that determines in which quadrant a coordinate (x, y) lies.

How it works

The program takes two inputs:

- x coordinate
- y coordinate

Then it checks the signs of x and y to determine the quadrant.

Quadrants

- 1st Quadrant → x > 0, y > 0
- 2nd Quadrant → x < 0, y > 0
- 3rd Quadrant → x < 0, y < 0
- 4th Quadrant → x > 0, y < 0

Example

Input:
3
-4

Output:
4
